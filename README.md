\# 🗡️ Realm of the Fallen Sword



Witaj w \*\*Realm of the Fallen Sword\*\* – dynamicznej grze stworzonej w języku Python przy użyciu biblioteki Pygame! 



\## 🎮 O grze

Gra powstała jako autorski projekt programistyczny. Łączy w sobie wciągającą rozgrywkę, własny system zapisu stanu gry (`savegame.json`) oraz unikalny klimat.



\## 🕹️ Sterowanie

\*(Tutaj możesz dopisać, jak się steruje, np.:)\*

\* \*\*Ruch:\*\* Strzałki / W, A, S, D

\* \*\*Atak:\*\* Spacja



\## 🛠️ Technologie i narzędzia

\* \*\*Język:\*\* Python 🐍

\* \*\*Silnik / Biblioteka:\*\* Pygame

\* \*\*Kompilacja:\*\* PyInstaller (plik `.exe`)



\## 🚀 Jak zagrać?

1\. Pobierz najnowszy plik \*\*`REALM\_OF\_THE\_FALLEN\_SWORD.exe`\*\*.

2\. Uruchom go i ciesz się rozgrywką! (Pamiętaj, aby pliki z grafiką/dźwiękami były w tym samym folderze, jeśli gra ich potrzebuje).
